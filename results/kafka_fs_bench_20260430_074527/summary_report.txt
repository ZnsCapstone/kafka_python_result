Latency Layers (이 보고서가 측정/구분하는 두 가지 latency)
  - App-level   : producer.send → broker ACK = 'broker 의 페이지 캐시 도달까지'
                  (Kafka client 가 인지하는 latency)
  - Block-level : iostat 의 await = 'I/O 가 block layer 큐에 들어간 후 완료까지'
                  (실제 디스크에 도달한 I/O 의 평균 처리 시간)
  두 값의 차이가 OS 페이지 캐시 + Kafka 큐잉의 latency 흡수 효과를 보여줌.
  fs 의 차이가 어느 layer 에서 나타나는지에 따라 ZNS 도입 motivation 이 달라짐.
